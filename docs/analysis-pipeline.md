# Watersight Satellite Analysis Pipeline

## 1. Evidence Upload
Users upload images containing geospatial metadata.

## 2. EXIF Extraction
The `extract_gps_data()` function converts native EXIF GPS DMS tags to Decimal Degrees (`EPSG:4326`).

## 3. AOI Generation
A precise 500-meter buffer is generated around the EXIF coordinates.
- **Library:** Shapely + GeoPandas
- **CRS Handling:** Coordinate is dynamically projected to the correct metric UTM zone, buffered by 500m, and reprojected to `EPSG:4326`.

## 4. Satellite Scene Discovery
- **Source:** Copernicus Data Space Ecosystem (CDSE)
- **Endpoint:** `https://stac.dataspace.copernicus.eu/v1/search`
- **Collection:** `sentinel-2-l2a`

## 5. Satellite Retrieval
To download actual Sentinel-2 L2A data without exposing Copernicus OAuth credentials, the CDSE Scene ID is seamlessly translated to the identical **Microsoft Planetary Computer STAC** archive. Assets are downloaded using unsigned SAS tokens dynamically generated by `planetary_computer.sign_inplace`.

## 6. 20m Raster Processing
- **Library:** Rasterio
- **Process:** Windowed reading (masking) using the AOI.
- **Bands Downloaded:** `B03` (Green), `B04` (Red), `B08` (NIR), `SCL` (Scene Classification).
- **Target Resolution:** Resampled from 10m to 20m using `rasterio.warp.reproject` (Bilinear interpolation).

## 7. Cloud Masking
Uses the Sentinel-2 **Scene Classification Layer (SCL)**.
Masks out:
- Cloud Shadows (3)
- Medium Probability Clouds (8)
- High Probability Clouds (9)
- Cirrus (10)
- Snow/Ice (11)
- NoData (0) and Saturated (1)

## 8. NDVI Processing
Calculated using NumPy: `(B08 - B04) / (B08 + B04)`
Safely handles division by zero and nodata masking.

## 9. NDWI Processing
Calculated using NumPy: `(B03 - B08) / (B03 + B08)`
Safely handles division by zero and nodata masking.

## 10. Statistics
Real NumPy statistics are calculated on valid (unmasked) pixels:
- `min`, `max`, `mean`, `median`, `std`, `valid_pixel_count`
- Vegetation Distribution (Very Low, Low, Moderate, High, Very High)

## 11. GeoTIFF Generation
The pipeline writes 3 standardized, georeferenced GeoTIFFs to `static/satellite/processed/<job_id>/`:
1. `ndvi_20m.tif`
2. `ndwi_20m.tif`
3. `cloud_mask.tif`

## 12. Map Visualization
Visualized on a dynamic Leaflet map using `L.imageOverlay`. Bounds are computed directly from the Rasterio affine transform and reprojected back to WGS84 for accurate web mapping overlay.

## 13. Charts
Rendered interactively using **Chart.js**. It categorizes the NDVI distribution percentage directly from the backend calculation.

## 14. Database Storage
Metadata is fully tracked in SQLite (`watersight.db`) under the `analysis_job` table, storing full state tracking, spatial bounds, and computed metrics for future historical comparisons.
